# Olive Frontend Clone

This project is a frontend recreation of a section from the Olive website, built based on a provided screenshot.

## Tech Stack
- Next.js 15 (App Router) + React 19
- TypeScript
- Tailwind CSS v4

## Run Locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Features
- Pixel-focused UI recreation
- Responsive layout
- Phone mockup carousel animation
- Avatar hover interaction

## Live Demo
[https://oliveclone.vercel.app/]
